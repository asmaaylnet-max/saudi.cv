# سجل قرارات المنتج المفتوحة

هذا ملخص تشغيلي للقرارات التي يجب حسمها قبل بناء السلوك المقابل. لا يستبدل سجل المالك المرجعي، ولا يتضمن الحزمة المرجعية أو بيانات شخصية. جميع البنود أدناه مفتوحة حالياً؛ لا تُستنتج قواعدها من الواجهات أو من التنفيذ.

| المعرّف | الموضوع | أثره العملي قبل الحسم |
|---|---|---|
| OD-01 | قواعد المسار، الحجز، التطبيع، النقل والنطاقات | لا يُفعّل إنشاء المسارات العامة أو حجز الأسماء اعتماداً على افتراض. |
| OD-02 | الظهور والمراجعة وأولوية الإخفاء والحذف والتنزيل والكاش | تُحجب وظائف النشر العام والبحث والتنزيل التي قد تتعارض مع الخصوصية. |
| OD-03 | الحفظ التلقائي والصريح والتعارض والعمل دون اتصال | لا تُبنى دلالة حفظ نهائية أو مزامنة مفترضة. |
| OD-04 | صلاحية OTP ومحاولاته وإعادة إرساله وتعريف حد الاستعادة | لا يُفعّل OTP أو استعادة الحساب حتى اعتماد السياسة وإرسال البريد الموثوق. |
| OD-05 | الحذف والاحتفاظ والسجل والمسار والنسخ | لا يُوصف حذف الحساب بأنه نهائي أو مكتمل قبل اعتماد دورة الحياة. |
| OD-06 | حقول النماذج والملفات والأدوار وحدود النشر | لا تُخترع حقول إلزامية أو متطلبات نشر للأدوار والعروض. |
| OD-07 | تعريف الزيارات والنقرات والجودة والاحتفاظ | لا تُعرض تحليلات أو أرقام اكتمال قبل تعريف المقاييس. |
| OD-08 | أولوية اللغة، نقص الترجمة، حفظ التفضيل وبطاقات المحتوى | تُحفظ اللغة كتفضيل عرض مستقل عن لغة ملف المستخدم. |
| OD-09 | معنى الدخول والقفل والتوثيق والفلاتر وإلغاء التوثيق | لا تُعلن إجراءات إشراف أو توثيق دون قواعد وصلاحيات محددة. |
| OD-10 | صلاحيات الإدارة والدعوات وحماية المشرف الرئيسي | لا إنشاء أو ترقية مشرفين أو تفويض صلاحيات في النسخة الحالية. |
| OD-11 | هوية الحساب المدار والمالك والمدير والمسار والتفويض | لا حسابات مدارة أو نقل نطاقات أو حسابات تابعة قبل الاعتماد. |
| OD-12 | البريد والإشعارات والإرسال الاحتياطي وسياسات الفشل | لا رسائل تسجيل أو OTP أو إشعارات مستخدمين قبل توثيق مرسل واختبار مأذون. |
| OD-13 | وجهات التواصل الفعلية وروابط الحسابات الاجتماعية | لا تُخمن عناوين أو أزرار تواصل غير معتمدة. |
| OD-14 | بدء الأسبوع المجاني ونهايته وما بعد الانتهاء | لا تفعيل عدّاد تجربة أو ادعاء آلي بشأن الاشتراك. |
| OD-15 | تصاميم PDF وATS وبطاقة 9:16 وQR/vCard ومصدر البيانات | لا يُعلن تنزيل مكتمل قبل اعتماد التصميم وضوابط إخفاء البيانات. |
| OD-16 | ميزانية الأداء وأجهزة وشبكات القياس | لا يوصف الأداء بأنه «خارق» دون قياسات موثقة على أجهزة وشبكات محددة. |

## قرار مرحلي: البريد والتسجيل (2026-11-22)

أكد المالك الإبقاء على منع ربط النطاق أو تعديل DNS، وترك البريد وOTP والتسجيل الفعلي معطلة حالياً. لا يُعد هذا اعتماداً لمزوّد أو نطاق مرسل مستقبلي؛ يبقى OD-12 مفتوحاً لأي تغيير لاحق في التفويض.

## بوابات حاكمة

- يبقى التسجيل والدخول وOTP وإرسال البريد غير مفعّلة إلى أن يثبت نطاق مرسل موثوق، وتعتمد سياسات الهوية والاستعادة ذات الصلة.
- لا تُستخدم حسابات أو ملفات أشخاص حقيقيين كبيانات تجريبية، ولا تُنشأ نتائج بحث أو عروض أو إحصاءات مصطنعة.
- أي قرار يمس البيانات الشخصية أو النشر أو صلاحيات المشرفين يتطلب اعتماداً صريحاً قبل التنفيذ، ويُعطّل بأمان عند غياب الاعتماد.
