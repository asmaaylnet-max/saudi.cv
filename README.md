# Saudi CV — staging

منصة الهوية المهنية السعودية — ظهور رقمي متكامل يليق بك.

واجهة أولية عربية أولاً، mobile-first، بخط Tajawal، مع دعم الإنجليزية وRTL/LTR والوضعين الفاتح والداكن. الأصول الموجودة هي أصول الهوية المصرح بها للمشروع.

## الحالة الحالية

الرابط المؤقت: https://saudi-cv-staging.pages.dev

الواجهة المنشورة تسمح باستعراض النسخة الأولية وتبديل اللغة والمظهر. التسجيل والبحث غير موصولين، ولا تُنشأ حسابات أو نتائج تجريبية. يوجد endpoint فحص تقني `/api/health` للتحقق من جاهزية D1 ووجود ربط R2 في بيئة staging؛ ولا يقدّم وظائف حسابات أو تخزين مستخدمين.

## النشر

يُبنى المشروع بواسطة `pnpm build` ثم يُرفع إلى مشروع Cloudflare Pages المخصص للتجربة باستخدام ملف `wrangler.toml`. راجع [توثيق بيئة staging](docs/staging.md) و[سجل القرارات المفتوحة](docs/open-decisions.md). لا تُودع أسرار Cloudflare أو البريد في Git، ولا تربط هذا المستودع بنطاق إنتاجي دون اعتماد منفصل.
